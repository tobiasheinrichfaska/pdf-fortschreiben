# Sicherheit

**Status:** Entwurf, nicht von einem Menschen sicherheitsgeprüft. Nicht für echte Daten verwenden.

## Schwachstellen melden

Bitte **nicht** als öffentliches Issue, wenn die Schwachstelle echte Daten gefährden könnte. Nutzen Sie
stattdessen die private Meldung über GitHub („Security“ → „Report a vulnerability“) oder schreiben Sie an
tobias.a.w.heinrich@gmail.com. Ich antworte, sobald ich kann; eine feste Frist gibt es nicht.

## Bitte nie in Issues, Pull Requests oder Commits ablegen

Echte Daten (Namen, Dokumente, Archive, Exporte), Passwörter, Schlüssel oder Zugangsdaten.

## Grenzen

Dieses Projekt ist keine Rechts- oder Steuerberatung und ersetzt keine Prüfung durch Fachleute. Bekannte
Grenzen stehen in `CLAUDE.md` unter „Known Limitations“.
